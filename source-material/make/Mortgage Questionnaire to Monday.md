# **📄 Summary of the Automation**

 This automation is designed to record all data from individuals who complete the JotForm questionnaire called "Real Savvy questionnaire" into the Monday table named "Mortgage Application."

# **🧭 High-Level Steps**

 The entire first part (from the first Tools to "All Special Items," inclusive) is used to make special fields or fields that come in complex formats from JotForm readable.

![Image: ](https://files.slack.com/files-pri/T08B8GHG3MK-F09GM0XU1DW/image.png)

 Then, using the "Parse JSON" step, we send which variable should go into each field of the Monday table.

![Image: ](https://rsfa-squad.monday.com/protected_static/18150562/resources/42945170/image-from-clipboard.png)

 Finally, we upload the data to Monday through JSON to ensure that all the information is recorded in a clear and tidy manner.

# **🔁 Run Cadence**

 **The flow is triggered when a person submits the questionnaire.**

# **✅ Conclusion**

 This automation eliminates the tedious task of manually entering each field into Monday. Additionally, it quickly makes all fields that come in complex formats readable.
