## 📄 **Summary of the Automation**

 This automation is triggered when an agent updates the **Adviser** column in an item on the [**Masterboard: End Forms**](https://rsfa-squad.monday.com/boards/5026186805) board, either to assign a new adviser or modify the existing one.

 

 Its purpose is to retrieve the details of the selected adviser and automatically update the same item with the relevant adviser information in the following columns:

-  **Adviser Contact Email**

-  **Adviser Contact Phone**

-  **Adviser Name**

-  **Adviser Firm**

 

## 🧭 **High-Level Steps**

1.  **Trigger on Adviser Update** – Runs when an agent changes the **Adviser** column in an item on the **Masterboard: End Forms** board.

![Image: ](https://rsfa-squad.monday.com/protected_static/18150562/resources/66343611/image-from-clipboard.png)

2.  **Retrieve Adviser Information** – Looks up the full details of the selected adviser.

![Image: ](https://rsfa-squad.monday.com/protected_static/18150562/resources/66343652/image-from-clipboard.png)

3.  **Update Adviser Details in the Same Item** – Updates the same item with the adviser’s contact and firm information in the corresponding columns:

-  **Adviser Contact Email**

-  **Adviser Contact Phone**

-  **Adviser Name**

-  **Adviser Firm**

![Image: ](https://rsfa-squad.monday.com/protected_static/18150562/resources/66343679/image-from-clipboard.png)

![Image: ](https://rsfa-squad.monday.com/protected_static/18150562/resources/66343699/image-from-clipboard.png)

 

## ✅ **Conclusion**

 This automation ensures that whenever an adviser is assigned or changed in the **Masterboard: End Forms** board, the related adviser details are automatically populated in the same item, making the information easier for agents to review and reducing the need for manual entry.
